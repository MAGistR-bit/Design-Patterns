## 👨‍🦱 Паттерн Одиночка
Паттерн Одиночка направлен на создание уникальных объектов,
существующих только в одном экземпляре.

> Паттерн Одиночка во многих отношениях представляет
> собой **_схему_**, которая гарантирует, что для заданного класса
> может быть создан один и только один объект.
